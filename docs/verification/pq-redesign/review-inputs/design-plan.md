## Graph meaning and identity

- A shared expression is one node with its existing metadata ID. Parameter/function labels remain hints with provenance available in Details; never claim evaluated type.
- A one-partition table uses its partition ID, title `Table`, subtitle `M · partition name`. Multiple partitions have distinct nodes titled `Table / Partition`, visually grouped by table if desired. No implicit union, collapse, or dependency on a selected partition. Table references with multiple candidates remain ambiguous until metadata genuinely resolves them.
- Every metadata node stays in the registry. Non-M/missing sources get muted nodes with status; tables with no partitions get a UI-only `table-status` node and no M/edges. Registry counts distinguish M queries, parameters/functions and status-only objects.
- A resolved static reference in consumer B to input A yields arrow A→B. Current analyzer graph returns consumer→referenced; reverse only in the adapter. Never modify the legacy analyzer edge direction silently.
- Parameter links are lavender and dashed, with explicit legend. Query input links are solid slate; related links highlight blue on selection. Arrowheads remain visible. Edge popover reads `A is referenced by B` plus reference location. Merge/append text appears only if proven by supported syntax; basic dependency edges need no operation guess.
- No semantic-model relationships, server/schema co-location, string/comment matches, or partition ownership edges may be promoted to M dependencies. No dummy SQL server node used to connect otherwise disconnected tables.
- Missing/dynamic/unsupported/ambiguous references are amber details on the consumer, not dashed speculative edges. Generic static-analysis caveat appears once in footer; object-specific uncertainty is actionable in Details. No-edge copy: `No query references resolved`, not a warning/error and not proof of independence.
- Cycles form stable components with cycle status; layout never assumes an acyclic graph.

## Interaction contract

Entry: select Power Query tab -> complete inventory + stable whole-model layout + Fit all; no table selection required; inspector closed. Remember viewport/selection while switching views within the same model.
Selection: click node or searchable library result -> selection outline + related edges + inspector. Canvas stays visible; selection does not remove other nodes. Blank click clears selection only. Escape closes inspector and returns focus to selected node. Optional Focus connections is explicit and has an obvious Back to all; not MVP default.
Code: exact read-only M, legible 12–13px Mono, line numbers, horizontal scroll, optional wrap, Copy M. Keywords purple, functions teal, strings amber, comments muted. Resolved reference occurrences are keyboard-focusable link-like tokens with underline and border, distinct from syntax color; parameter links lavender. Use scope-aware resolved occurrence ranges, never name regex. Click/Enter selects and reveals target, updates inspector and canvas focus, adds history. Back restores prior selection + viewport + code scroll. Unresolved tokens expose reason without a clickable invented target. Copy preserves exact source bytes including CRLF.
Canvas: same drag-background pan and wheel/pinch conventions as Tables; drag nodes for layout only; +/− zoom, F Fit all, keyboard arrow pan when canvas focused, Tab entry/exit with roving focus among nodes and Enter selection. Inputs/code do not trigger graph shortcuts. Toolbar controls have labels/focus rings. Fit accounts for inspector/library bounds. Search filters library + dims nonmatches, never deletes registry or changes global graph counts. Jump reveals at readable zoom. Drag selection is optional post-MVP, not a prerequisite.
Responsive: 1440/1280 desktop retained canvas; inspector can resize/collapse. 1024 or narrow split uses inspector below. No full-screen modal. 200% browser zoom and keyboard-only use remain possible through library.
Model reset: model AND metadata identity invalidate analysis, selections, history, layout, search, inspector, async work, retained code. Late callbacks cannot repaint old model. Switching back to Tables must not overwrite its state.
Large models: all nodes in registry, all components in initial overview; viewport culling/semantic zoom permitted but no silent first-80/first-200 caps. Search reaches last object. Incremental analysis explicitly shows analyzed/total, partial edges, cancellation on model switch; nonanalyzed is never labeled no-dependency. Default overview has no mandatory expand-to-discover path. Minimap/counts reflect whole model. Test 300/301/350/1000 inputs and shared parameter with >200 consumers; record performance rather than inventing completion claims.
Privacy: current snapshot allowlist excludes raw M and Power Query metadata. New UI module files may be shipped, raw source values may not. No M execution, connector call, credential access, source-model edit, or network source fetch.

A2. Parameter Server referenced by 5 queries: one Server node, exactly five outward arrows, all consumers present initially. A local let-binding named Server plus a string/comment Server produces no extra edges. Select parameter highlights all five; no values leaked into export.

Table.Combine and Table.NestedJoin include all static input references without invented execution order.
A4. In MergeResult M, click each resolved occurrence (quoted names, repeated occurrences and parameter included): exact target ID selected/revealed, inspector follows, Back restores former viewport/scroll. Local names, fields, comments, strings and unresolved tokens never navigate.
A5. Mouse + keyboard: pan, zoom, Fit, library search, last search result, node select, code-link Enter, Escape, Back; no stolen text-input keys, visible focus, no trapping. At 1280/1440 and 200% zoom labels/controls not obscured by inspector.
A6. 300/301/350/1000 query cases: total inventory remains correct across thresholds, disconnected last node findable, high-fanout last consumer reachable, no arbitrary graph clipping presented as complete. Progress is explicit; model-switch cancels pending work.
A7. Missing/non-M, dynamic expression, unresolved name, duplicate identity, two partitions with same table name and cycles: no guessed edges, reasons inspectable, stable IDs distinguish partitions. Query with ambiguous table reference has no single-partition link. Same-named shared expression/table obeys resolver's ambiguity semantics.
A8. Import model B while A selected/code open and async analysis pending: no A nodes, M text, history, cache, labels or callback effects survive. Switch tabs and import snapshot without M: correct unavailable explanation, not stale prior code.
A9. Snapshot/default sharing, unchanged exact M fixtures including CRLF, XSS text fixture, no source network requests/M evaluation. Canonical source and generated extension media checks; packaged/installed evidence separate.
A10. User personally reviews redesigned UI using representative model and signs off product fit. Automated pass, proposal screenshot or historical #38 evidence cannot satisfy A10.

## Frozen prerequisite interfaces for delegation

Proposed new `PowerQueryGraphModel.build(model)` -> `{nodes, edges, issues, analysisProgress}`. Node `{id, metadataId, label, subtitle, kind, table, partition, state}`; status-only nodes have null metadataId. Edge `{id,inputId,consumerId,referenceOccurrences}`. Full metadata ID must survive; derive stable edge ID from input/consumer IDs. Issues structured `{consumerId,kind,message,at?,end?}`; old analyzer string uncertainty can be retained until structured safely. Do not silently classify strings by fragile regex as semantic facts.
Extend analyzer additively with `references:[{id,name,at,end}]` for every resolved occurrence while retaining existing `dependencies` and graph APIs. Both are emitted by the same scope walk; parse failure clears references AND dependencies. Offsets are UTF-16 source positions, end-exclusive. Scope-aware analysis is sole navigation authority.
`PowerQueryCanvas.mount(host,{graph,onSelect,onViewport}) -> {setGraph,setSelection,reveal,fit,getViewport,setViewport,destroy}`; diagram owns geometry/events only, no shell or parsing. `PowerQueryInspector.mount(host,{metadata,onNavigate,onClose}) -> {select(nodeId),destroy}`; exact source display and link ranges only, no graph construction. Coordinator owns shared state/history/lifecycle.
These interfaces are proposed and must be reviewed; if a worker finds incompatibility, report rather than independently changing other slices.
