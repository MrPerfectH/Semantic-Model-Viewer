# Selection and explicit focus lock (r10)

The 2026-10-10 request supersedes the automatic-first-query root and the top flow strip in the earlier flow/r9 contracts. Ordinary card/library selection still preserves numeric viewport, body scroll and positions. Without a lock, focus uses the current selection. `flowRootId` now records only an explicit lock; the inspector lock button exposes pressed state, accessible action name, keyboard activation and release hint. Selecting another query while locked keeps the root and shows the selected query even outside the root's hide projection. Unlock releases the root immediately; no lock action fits or arranges. Direct input/consumer buttons and exact inline M links remain deliberate reveal navigation. Back restores selection, root, direction/depth, membership, viewport and source view. Legacy trace/frame methods remain callable for history compatibility but are no longer primary navigation.

Dim/hide and direction/distance act on the locked root or current selection. Reset filters preserves the lock, as it preserves selection/focus settings; Show all and Blank release it; removing the root releases it. New model generations clear it. None of this is persisted or exported. The small inspector icon replaces the former top strip/dropdowns/follow buttons; there is no new control panel.

Fit frames existing visible positions and never changes them. Arrange compacts the current visible induced graph and fits it, retaining hidden-node positions; Undo restores exact per-ID positions and viewport. For 2–8 visible queries, a nearby **Arrange compact** button makes the repair a single explicit action, including two cards retained at distant full-model coordinates. Filtering/ordinary selection never silently rearranges manually positioned cards.

Selected cards have full opacity immediately, even outside a locked focus. Fact header text uses the dark Tables-style header. Unrelated cards remain recognizable at 65% opacity, edges at 55%; paths use non-scaling 1.8px strokes. Parameter dashes, semantic direction, reciprocal routes, hit ports and cycle identity are unchanged. Overview cards prioritize readable title and kind; source provider remains in the tooltip/inspector and in card footers at detail scale.

Presentation has two independent axes. Partition/table association establishes **Model table**, parameter metadata establishes **Parameter**; source-call evidence establishes **Source query** or **Inline table**. Resolved query inputs support **Intermediate query**. Otherwise kind/provider remain unknown. Inline construction does not prove Enter Data authoring, loading, refresh, execution or physical lineage. Fact/dimension badges/colors use the existing actual table classification.

The existing bounded M parser records only an explicit list of exact direct calls after lexical and exact model/duplicate resolution: PowerPlatform.Dataflows, PowerBI.Dataflows, Databricks.Catalogs/Contents, Sql.Database/Databases, Snowflake.Databases, OData.Feed, AzureStorage.DataLake, Excel.Workbook, Web.Contents, File.Contents, Table.FromRows and #table. Call arguments are never retained in evidence. Comments, strings, uncalled identifiers, field/item access, shadowing, ambiguous model identities and incomplete parses cannot establish a provider. Multiple recognized providers are **Mixed**. Observed calls may be conditional or in unused code: they do not establish executed sources, and upstream query references do not propagate provider claims. There are no external graph nodes, name heuristics, fetches or M execution. The 12 standard-library names and model precedence remain unchanged.

Frozen r7/r8 automation is retained verbatim as evidence. Executable adaptations change only explicitly superseded entry actions: select distance All deliberately instead of relying on auto-first-root, use direct inspector input navigation, omit the removed Trace toolbar action, and omit diagnostics for the removed flow bar. All remaining geometry, focus ownership, reader, source/privacy, 200% zoom and Arrange/Undo assertions stay intact. New regressions cover the replacement policy.
