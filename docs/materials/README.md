# Learning material sources

The public entry point is the [learning library](../learning-library.md).
This file records the source of its selected assets for future maintenance.

## PDFs

`focus-your-canvas-classic.pdf` and `focus-your-canvas-spellbook.pdf` are unchanged
copies of the final v8 four-page PDFs prepared on October 25 for the October 26,
2026 canvas-focus post. Classic was the selected posting edition; Spellbook is
an alternative appearance of the same walkthrough.

Original filenames:

- `Semantic-Model-Viewer-classic-4-slides-v8-final.pdf`
- `Semantic-Model-Viewer-spellbook-4-slides-v8-final.pdf`

Both use synthetic Contoso Retail captures. The captures included a local
relationship-label fix subsequently released in stable 0.4.3. Earlier drafts are
not part of this collection. The v8 revisions clarified instructions and table
counts; these copies do not introduce new PDF edits.
