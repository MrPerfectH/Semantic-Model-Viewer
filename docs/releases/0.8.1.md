# Semantic Model Viewer 0.8.1

Stable patch release, 13 November 2026. It fixes what the platform tests of
0.8.0 found. 0.8.0 shipped without those tests; they were run afterwards on
Windows 11, macOS 27 and Linux.

## Fixes

- **Plugin updates.** The Claude Code and Codex plugin, and the bundled `smv`
  command, now carry the extension's version. The plugin manifest still said
  0.7.0 in 0.6.0 and 0.8.0. Claude Code keeps the installed copy while the
  manifest version is unchanged, so plugin users did not receive those
  releases. Run `claude plugin update` to get 0.8.1.
- **Open Power Query.** Selecting a table and choosing **Open Power Query**
  opens that table's flow and M code on the first click. The first click
  opened an empty Power Query view with nothing selected; later clicks worked.
- **Accessibility:**
  - Secondary grey text in Tables, Measures, Power Query, Table groups and Matrix meets the 4.5:1 contrast ratio in the Classic theme.
  - The Measures library resize handle reports its value to screen readers.
  - At 400% zoom the Matrix headers scroll with the table instead of covering every cell.
  - **Fit overview** and **Arrange compact** in Power Query have accessible names that contain their visible labels.
  - The wrapped Power Query navigation bar stays above the status line on narrow panes.
- **Links to a missing target.** A command or artifact folder that is such a
  link is refused with a clear message. The checks let it through, and the CLI
  launcher could be written through it.
- **Power BI Desktop connection** (pre-release builds only). Each open model is
  listed under its report's name, the internal row-number column no longer
  appears in every table, and hierarchies are included.

The 11 Windows failures do not come from the product: eight need LF line
endings and a `python3` command, and three create a junction to a short
(8.3) path. The eight pass once those two conditions are met.

## Known limits

- More low-contrast grey text remains in states the scan did not open.
- Measures library rows and Matrix row headers still fail the
  `label-content-name-mismatch` rule.
- In VS Code on macOS, a view update times out as "hidden" while the VS Code
  window is fully covered by other windows.
- The demo model is not valid TMDL for Microsoft's parser, so Power BI Desktop
  cannot open it. The viewer opens it.
- Not tested: screen-reader speech output, the External Tools ribbon button,
  the VS Code command that connects to Power BI Desktop, and a live Fabric
  reopen.

## Not in this stable release

- The VS Code Power BI Desktop connection and External Tools button (#162)
  stay hidden in stable builds.
