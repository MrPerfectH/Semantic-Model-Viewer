# Semantic Model Viewer 0.8.0

Stable release, 13 November 2026. It promotes `develop` to `main`; the previous
stable was 0.6.0, released on 30 October 2026. The version is 0.8.0 because
pre-releases 0.7.x are already on the Marketplace and stable uses even minor
versions.

## Highlights

- **Reference** (#220): a searchable page for every table, column, measure,
  calculation group and item, hierarchy and Power Query object.
  - Each page shows the definition, properties and links to related objects, and **Back** retraces your steps.
  - **Explore relationships** and **Explore dependencies** open the object in Tables or Measures.
  - Descriptions are read from the model and never generated. Guide: `docs/model-reference.md`.
- **DAX for calculated objects** (#220):
  - **Show DAX calculation** opens calculated tables, calculated columns, field parameters and calculation groups in Measures.
  - Their formulas use the same DAX cards and reference chips as measures.
  - **Show calculated objects** adds the calculated consumers of the visible fields to a measure flow.
- **Safer imports** (#205, #211):
  - A model is checked before it replaces the open one, so a failed load keeps the previous model.
  - Object names that clash with built-in names load and reload correctly.
  - Parallel relationships are kept, and anything left out during import is listed by name.
- **Relationships and keyboard** (#206, #207, #213):
  - A click selects the nearest visible relationship, and repeated clicks at an exact overlap cycle through the tied ones.
  - Relationship glyphs are one Tab stop with arrow-key movement, and **Skip to table library** skips the canvas cards.
  - The import dialog keeps focus inside it, closes on Escape and returns focus to its opener.
- **Small screens** (#209, #212): below 800px, Measures switches between the library and the reader. Fit takes open panels into account and keeps a view you framed by hand.
- **Large models** (#208, #215, #216):
  - Power Query opens its inventory before any overview routing.
  - Dense Tables diagrams route in bounded time and show a notice when the limit is reached.
- **Exports** (#214): PNG export is bundled and works offline, and leaves out tooltips, popovers and hidden tables. Snapshots state what they contain before you share them.
- **Help** (#218): contextual Help from the toolbar, and tips that stay clear of the search box on narrow screens.
- **Dependencies** (#200): `@azure/msal-node` 7.1.1 in the extension and the standalone Fabric helper, and newer GitHub build actions.

## Known limits

- A dense overview can still draw lines across cards. All relationships stay
  present; **Focus** gives a clear local view.
- A very large Power Query overview is deferred. The inventory and the focused
  flow of a chosen query work.
- A snapshot contains the captured model metadata, not only the selected view.
  It is not a redaction tool.

## Not in this stable release

- The VS Code Power BI Desktop connection and External Tools button (#162) stay
  hidden in stable builds until the Windows test passes. They remain in
  pre-release builds.
- Explaining relationship differences when comparing measures (#173).
- Fabric capacity diagnostics (#199).

## Validation

- CI on every merged PR and on this release PR, and the release workflow after the tag.
- The audit work (#203) passed 967 unit, host and CLI tests with 3 environment
  skips, and 51 browser tests, on Linux. An independent review found no blockers.
- Not verified on Linux: Windows with Power BI Desktop, the macOS launcher,
  screen-reader output and high browser zoom.
