# Semantic Model Viewer 0.5.0 (draft)

Draft stable release notes. Stable 0.4.3 was released on 26 October 2026; this
release promotes `develop` to `main`. The latest pre-release candidate is
**0.7.364**, from `develop` d8317a2.

## Highlights

- **Readable diagrams without zooming** (#187, #190):
  - Table and measure names render at 11px or larger on first open.
  - **Focus** shows a table's direct neighbourhood, arranged, and pressing it again restores the layout.
  - On short windows the legend, overview map and status line step aside, and the canvas bar fits one row.
  - The Measures header is one row, and narrow dependency flows run top to bottom with right-angle links that never cross a measure.
  - The readability bar and its measurements are in `docs/qa/diagram-readability.md`.
- **Agent workflow:**
  - Agents can now explain models visually and drive a live viewer: CLI-authored visual explanations (#92), interactive viewer sessions through the CLI and MCP (#108), and prepared views (#129).
  - `smv show` opens a Tables + Measures workspace: side by side, or as tabs below 1100px (#160, #182, #187).
  - Answer views open on the diagram alone, and the agent states the answer in the conversation.
- **Fabric connection:**
  - Work-account sign-in, workspace and model browsing, read-only metadata, offline reopening and refresh (#149).
  - The sidebar shows a local models group (#168).
  - Direct Lake labels are fixed (#169).
  - Refresh keeps its context (#174).
- **Colours and themes:**
  - Edit colours by source or table folder, with a compact legend (#165).
  - Follows VS Code light, dark and high-contrast themes (#154, #155, #158).
- **Bundled delivery:**
  - The extension packages include the `smv` CLI and native Copilot tools.
  - The same delivery is bundled for Claude Code and Codex (#167, #177).
  - Measure comparison (#177).
  - A portable Windows build with bundled Python (#161).
- **Onboarding:** clearer model setup and optional contextual tips (#125).
- **Fixes:**
  - Card hover and line attachment (#134).
  - Matrix width on Windows VS Code (#178).
  - Clearer live viewer exports (#181).
  - Windows VSIX targets (#183).
  - Windows CLI launchers under legacy code pages (#184).

## Not in this stable release

- The VS Code Power BI Desktop connection and External Tools button (#176) stay
  hidden in stable builds (#189) until the Windows test passes. Before tagging,
  check whether the Windows installer's External Tools registration (#111, #128)
  needs the same gate.
- The proposed measure-graph line colours (Inputs / Used by) are planned for the
  next release.
