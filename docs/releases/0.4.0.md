# Semantic Model Viewer 0.4.0

Stable release assembled from main 80361ab and selected develop changes through a0b758d.

## Included

- Existing main improvements: Spellbook palette and Tables toolbar (#77), fresh-snapshot launcher (#124).
- Core measure browsing and filtered formula overview (#127).
- Table/column dependency analysis, source navigation, colored formula-owned reference chips and snapshot state (#130).
- Snapshot connected/direct/inactive-inclusive defaults (#133).
- Stable-height table hover controls (#134).
- Usable stacked graph canvas, accurate layout label and reachable DAX (#135).

The final shared Measures runtime was extracted from develop with agent-session/capture hooks removed. The core app retains main's startup behavior; onboarding was removed. Main's launcher and its tests are preserved.

## Deferred

Guided onboarding (#125); new visual explanations/live agent sessions (#92/#108/#129); MCP and inline apps; Windows External Tools registration (#111/#128). The existing snapshot CLI is unchanged. Develop remains the preview branch.

## Limits

Static DAX reference analysis does not execute queries or traverse calculated-column/table defining expressions or relationship filter propagation. No new large-model performance claim.

## Validation

- Node 22: 694 viewer/extension/CLI/launcher tests passed, zero failures or skips.
- Real Chromium: 22 checks passed, including complete-viewer source analysis, both themes, stacked layout, long-name hover stability, downloaded offline snapshots and re-export.
- Stable VSIX: 46 entries, version 0.4.0, no pre-release manifest property; generated runtime files match the canonical source byte for byte. No MCP, inline/interactive agent renderer, onboarding or Windows registration assets.
- macOS: installed the local VSIX into an isolated extensions directory and activated it in standard VS Code against a synthetic Contoso project. Native UI rendered 43 tables / 68 relationships and no onboarding. This is an activation/render smoke check; detailed interaction evidence comes from Chromium checks above.
- Initial Linux run failed from the temporary-directory quota. Successful runs used a writable TMPDIR and Node 22. Browser harness cleanup was corrected to close Chrome gracefully before deleting its profile.
- Added both real-browser suites to PR CI. Hosted CI and public release/Marketplace delivery are verified after the release PR.

The existing release workflow needs no root MCP dependency installation because the deferred MCP tests/dependencies are not included in this selected release.
