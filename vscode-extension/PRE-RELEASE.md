# What's new in the pre-release

The Fabric development preview adds the following to the stable 0.4.3 release:

- **Connect to Fabric:** sign in with a work account, browse workspaces and semantic models, and open their metadata in the viewer.
- **Reopen cached models offline:** refresh or remove saved metadata and switch accounts when needed.
- **Choose a connection path:** use XMLA or, from the connection command, the Fabric definition API when available.

Fabric access depends on your account permissions and workspace configuration. See the Fabric connection section below for requirements, supported platforms, and current limitations.
